# AI Foundations

## Traditional vs AI Applications

**Traditional software**

* Uses fixed rules and logic.
* Same input usually gives the same output.
* Examples: CRUD, payments, authentication, SQL search.

**AI-powered software**

* Adds model intelligence to applications.
* Handles meaning, prediction, generation, personalization, and natural language.
* Results can be probabilistic, so validation is important.

## Keyword vs Semantic Search

* **Keyword search:** matches exact words.
* **Semantic search:** finds content based on meaning using embeddings and vectors.

AI does not replace normal code or SQL. It adds intelligence where fixed rules are not enough.

## Why AI Is Growing

* **AI APIs:** allow developers to use powerful models without training them.
* **GPUs:** make training and inference faster.
* **Developer tools:** simplify AI application development.
* **Vector databases:** enable meaning-based information retrieval.
* **Streaming:** makes AI responses feel faster and more interactive.

## AI in Real Applications

AI is used for:

* Code assistants
* Recommendations
* Price and travel-time prediction
* Route selection
* Matching users and services

## AI Coding Tools

AI can help with:

* Autocomplete
* Code generation
* Debugging
* Refactoring
* Testing
* Explaining code

Context and clear instructions improve results.

## Main Lesson

AI is a **developer assistant, not a replacement for understanding**.

> Never accept code you cannot explain.

**Use AI to develop faster, but keep the understanding and responsibility yourself.**
